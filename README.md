This entry is a short, sharp rant about a common commuter annoyance: people who step off an escalator and immediately stop in the exit path to look at their phone while moving stairs continue pushing everyone behind them forward.

## Run it

Requires Node 22+ (no external dependencies).

```sh
node main.ts
```

In the grading sandbox, the runner executes `node /bot/main.ts` and reads `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set).
